## Featured Projects

### Kestrel

**WASM virtual machine and DRM runtime infrastructure.**

Kestrel is my WebAssembly VM project focused on compact runtime design, protected execution, encryption-oriented control flow, and tamper-resistant software systems. It reflects my strongest current interests: VM internals, runtime architecture, low-level program representation, and security-focused systems design.

**Tech:** Rust, JavaScript, WebAssembly, VM design, runtime security, encryption-oriented architecture

### Apex DMA Research

**C++ memory research project exploring DMA-oriented tooling and protected runtime environments.**

Apex DMA is a private/research-oriented project focused on frontend/backend architecture, shared cross-process structures, DMA-backed memory interaction, and the security boundaries around modern protected game processes. The public organization repo lives under `wednesdaywtf/apex-dma`.

**Tech:** C++, CMake, DMA hardware, Windows internals, memory analysis

---

### Source Engine Tooling

**Internal, external, and driver-level tooling for Source engine titles.**

I built C/C++ tooling around CS:GO and TF2 to study Source engine internals, entity systems, runtime structures, hook-based instrumentation, and Windows process interaction. Public organization repositories include CS:GO internal/external projects, a CS:GO external driver, and a TF2 internal framework.

**Tech:** C++, C, Win32 API, CMake, Source engine, runtime instrumentation, Windows internals

---

### CigFinder

**Pure C signature scanner for binary-analysis workflows.**

CigFinder is a small, dependency-light signature scanner using IDA/YARA-style byte patterns. It was designed for direct `.text` section scanning inside Win32 applications, with a focus on simple integration and minimal overhead.

**Tech:** C, Win32, signature scanning, byte-pattern matching, binary analysis

---

### Runtime Modification Tooling

**C# runtime patching and modding projects for Unity/Mono-based games.**

I have built runtime modification tools using BepInEx, MelonLoader, and compiled assembly analysis. These projects helped me build practical experience with managed runtime behavior, IL-level state modification, plugin systems, and reverse engineering Unity-based games.

Public examples include:

- [musedash-unlocker](https://github.com/ckaspian/musedash-unlocker)
- [death-must-gamble](https://github.com/ckaspian/death-must-gamble)
- [wednesdaywtf/lethal-company](https://github.com/wednesdaywtf/lethal-company)

**Tech:** C#, BepInEx, MelonLoader, Unity, Mono/IL analysis, runtime patching
